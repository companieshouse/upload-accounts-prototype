Use this service to file package accounts with Companies House.

You can file package accounts for:

  • Community Interest Companies (CIC) - there is a £15 fee to file
  • overseas companies - there is a £34 fee to file
  • audit exempt subsidiary accounts
  • dormant exempt subsidiary accounts
  • limited partnership accounts
  • UKSEF accounts for listed companies
  • group package accounts - section 400, parent incorporated under UK law
  • group package accounts - section 401, parent incorporated under non-UK law
  • Welsh accounts with an English translation

What you'll need

You must use suitable software to prepare the accounts and save them in a ZIP file format. You cannot create the ZIP file manually.

Use our tool if you need to find suitable software.

You'll need:

  • the package accounts ZIP file
  • to sign in or create sign in details
  • the company name or number
  • the company authentication code
  • to pay the fee using a credit or debit card, if relevant

! Warning If your package accounts have not been prepared using suitable software, we will reject them.

This service will time out if you do not use it for 60 minutes. Your answers will not be saved.

Preparing your package accounts

The software you use will prepare your package accounts for you. You should not need to do any additional checks.

However, if you’d like more information or to check a file, you can:

  • find details of all available taxonomies and guidance for filers and developers on the Financial Reporting Council (FRC) website
  • check your accounts files are valid using the iXBRL accounts test service
